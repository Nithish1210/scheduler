# Scheduler

## Description

An administrative application for managing scheduled periods and reallocations.

## Notes

1. Do not push directly to the `main` branch.
2. Report your progress before committing to `main`.
3. Do not write, overwrite, alter, or delete database data.
4. If database changes are authorized, back up the database before and after making them.

## Branches

Push changes to the appropriate branch:

1. `ui` — Front-end UI development.
2. `backend` — Application and subprocess development.
